# Project Summary

SAKAN — многоязычная платформа знакомств и создания семейных отношений. MVP объединяет регистрацию пользователей, профили, поиск совместимых участников, общение, подписки и управление фотографиями в едином branded-продукте с арабской и английской поддержкой.

# Project Module Description

- **Аутентификация и пользователи** — регистрация, вход, callback-обработка, выход и управление пользовательскими данными.
- **Профили и onboarding** — создание и редактирование профиля, предпочтения, биография, местоположение и семейные параметры.
- **Discovery** — просмотр анкет, поиск и фильтрация участников.
- **Связи** — избранное, посещённые профили, блокировки и жалобы.
- **Сообщения** — диалоги и обмен сообщениями с ограничениями бесплатного тарифа и проверкой блокировок.
- **Фотографии** — загрузка, удаление, выбор основной фотографии через object storage.
- **Подписки и платежи** — каталог планов, Stripe Checkout, проверка платежа и серверное обновление premium-доступа.
- **Администрирование и системные функции** — health-check, настройки, storage, telemetry и API для системных интеграций.
- **Контент** — блоговые страницы, Markdown-статьи, sitemap и prerender-маршруты.
- **Демо-данные** — три плана подписки и двенадцать тестовых профилей для проверки discovery.

# File Description Inventory

## Backend

- `main.py` — создаёт приложение и подключает автоматически обнаруживаемые роутеры.
- `lambda_handler.py` — адаптер запуска backend в serverless-среде.
- `core/auth.py`, `dependencies/auth.py`, `services/auth.py` — аутентификация и проверка текущего пользователя.
- `core/database.py`, `dependencies/database.py`, `services/database.py` — подключение и работа с базой данных.
- `core/config.py`, `core/environment.py` — конфигурация и переменные окружения.
- `core/mask_crypto.py` — криптографические и маскирующие функции.
- `core/telemetry/` — HTTP-, SQLAlchemy-, timing- и request telemetry.
- `models/` — ORM-модели профилей, предпочтений, фотографий, связей, сообщений, платежей и планов.
- `schemas/` — структуры запросов и ответов для auth, storage и AI-интеграций.
- `routers/` — публичные, защищённые, платежные, storage, пользовательские и доменные API.
- `services/` — операции CRUD, discovery, messaging, payment, storage, AI Hub и пользовательская бизнес-логика.
- `alembic/versions/82045b46703c_auto_update.py` — текущая миграция схемы.
- `data_models/` — декларативные JSON-описания таблиц.
- `mock_data/` — исходные данные для локального или демонстрационного наполнения.
- `skills_docs/` — документация по AI, storage, custom API и Web SDK.
- `requirements.txt`, `requirements.default` — зависимости Python.

## Frontend

- `App.tsx` — корневая композиция приложения и маршруты.
- `contexts/AuthContext.tsx` — состояние текущей сессии.
- `lib/api.ts`, `lib/auth.ts`, `lib/sakan.ts` — API-клиент, auth-логика и доменные вызовы.
- `pages/` — landing, onboarding, discovery, профили, связи, сообщения, подписка и auth callback-страницы.
- `components/sakan.tsx` — общие branded-компоненты SAKAN.
- `components/blog/` — layout и Markdown-рендеринг статей.
- `components/ui/` — переиспользуемые элементы интерфейса на базе shadcn/Radix-подхода.
- `api/settings.ts` — клиентские настройки приложения.
- `prerender/` — генерация blog routes, статей и sitemap.
- `App.css`, `index.css` — глобальные стили и тема.
- `public/assets/sakan-brand.png` — основной брендовый artwork.
- `package.json` — скрипты, зависимости и lockfile-экосистема frontend.
- `site.config.json`, `template_config.json` — настройки сайта и шаблона.
- `vite.config.ts`, `tsconfig*.json`, `eslint.config.js` — сборка, TypeScript и lint.
- `tailwind.config.ts`, `postcss.config.js` — CSS-пайплайн.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/Radix UI.
- **Backend:** Python, FastAPI, Pydantic, SQLAlchemy.
- **Database:** реляционная БД через SQLAlchemy и Alembic.
- **Authentication:** встроенная Atoms Cloud authentication.
- **Storage:** Atoms Cloud object storage с загрузкой через SDK и сохранением object keys.
- **Payments:** Stripe Checkout и серверная верификация платежей.
- **AI/Platform integrations:** Atoms Cloud Web SDK, AI Hub и custom API.
- **Content:** Markdown-блог с prerender и sitemap generation.
- **Quality tools:** ESLint, TypeScript, production build, Python syntax checks.
- **Deployment model:** cloud/serverless-compatible backend с frontend-сборкой Vite.

# Usage

## Backend

```bash
cd app/backend
pip install -r requirements.txt
alembic upgrade head
```

Настройте переменные окружения для базы данных, аутентификации, storage и Stripe в соответствии с конфигурацией проекта.

## Frontend

```bash
cd app/frontend
pnpm install
pnpm lint
pnpm build
```

Для разработки используйте скрипт проекта:

```bash
pnpm dev
```

## Запуск всего приложения

```bash
cd app
bash start_app_v2.sh
```

После запуска доступны onboarding, discovery, профили, сообщения, подписки и блоговые страницы. Для реального платежного сценария требуется подключённый Stripe-аккаунт; тестовые платежи выполняются в Stripe test mode.
