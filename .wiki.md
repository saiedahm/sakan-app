# Project Summary

SAKAN — многоязычная платформа знакомств для поиска партнёра и создания семейных отношений. Продукт объединяет регистрацию, профили, рекомендации, поиск, общение, подписки, продвижение анкет и управление фотографиями. Интерфейс поддерживает арабский и английский языки, а главная страница показывает рекламные слоты, избранных и новых участников, промо-предложение за 99 центов и актуальные статусы присутствия.

# Project Module Description

- **Аутентификация и пользователи** — регистрация, вход, callback-обработка, выход и управление пользовательскими данными.
- **Профили и onboarding** — создание и редактирование анкеты, биография, предпочтения, местоположение и семейные параметры.
- **Главная страница** — публичный home API, рекламные слоты, избранные и новые участники, промо-баннер подписки и навигационные сценарии.
- **Discovery** — поиск и фильтрация анкет с режимами `latest`, `nearby` и `online`, включая deep-link параметры поиска.
- **Присутствие** — heartbeat и отображение онлайн-статуса пользователей.
- **Связи** — избранное, посещённые профили, блокировки и жалобы.
- **Сообщения** — диалоги и обмен сообщениями с ограничениями бесплатного тарифа и проверкой блокировок.
- **Фотографии** — загрузка, удаление и выбор основной фотографии через object storage.
- **Подписки и платежи** — каталог планов, Stripe Checkout, серверная проверка платежей и premium-доступ, включая промо-сценарий за 99 центов.
- **Реклама и продвижение** — управление рекламными слотами и промо-кампаниями.
- **Администрирование и системные функции** — health-check, настройки, storage, telemetry и интеграционные API.
- **Локализация** — переключение арабского и английского языков, языковые настройки и RTL-поддержка.
- **Контент** — блоговые страницы, Markdown-статьи, sitemap и prerender-маршруты.
- **Демо-данные** — тестовые профили, планы подписок, рекламные слоты и промо-данные.

# File Description Inventory

## Backend

- `main.py` — создаёт FastAPI-приложение и подключает автоматически обнаруживаемые роутеры.
- `lambda_handler.py` — адаптер запуска backend в serverless-среде.
- `core/auth.py`, `dependencies/auth.py`, `services/auth.py` — аутентификация и проверка текущего пользователя.
- `core/database.py`, `dependencies/database.py`, `services/database.py` — подключение и работа с базой данных.
- `core/config.py`, `core/environment.py` — конфигурация и переменные окружения.
- `core/mask_crypto.py` — криптографические и маскирующие функции.
- `core/telemetry/` — HTTP-, SQLAlchemy-, timing- и request telemetry.
- `models/` — ORM-модели пользователей, профилей, предпочтений, фотографий, связей, сообщений, платежей, планов, рекламы, presence и promotions.
- `schemas/` — структуры запросов и ответов для auth, storage, AI и доменных API.
- `routers/sakan_core.py` — основные публичные и защищённые API, включая home/discovery и presence-интеграции.
- `routers/sakan_payments.py` — планы, checkout, платежная проверка и premium-доступ.
- `routers/Adslots.py` — API рекламных слотов с контролем доступа к административному списку.
- `routers/Presences.py` — регистрация heartbeat и получение статусов пользователей.
- `routers/Promotions.py` — API промо-кампаний и продвижения.
- `services/` — CRUD, discovery, messaging, payment, storage, AI Hub и пользовательская бизнес-логика.
- `alembic/versions/` — миграции схемы для новых сущностей и текущих изменений.
- `data_models/` — декларативные JSON-описания таблиц.
- `mock_data/` — исходные данные для локального и демонстрационного наполнения, включая планы и рекламные слоты.
- `skills_docs/` — документация по AI, storage, custom API и Web SDK.
- `requirements.txt`, `requirements.default` — зависимости Python.

- `api/settings.ts` — клиентские настройки приложения.
- `prerender/` — генерация blog routes, статей и sitemap.
- `App.css`, `index.css` — глобальные стили, тема и RTL-настройки.
- `public/assets/sakan-brand.png` — основной брендовый artwork.
- `package.json` — скрипты и зависимости frontend.
- `site.config.json`, `template_config.json` — настройки сайта и шаблона.
- `vite.config.ts`, `tsconfig*.json`, `eslint.config.js` — сборка, TypeScript и lint.
- `tailwind.config.ts`, `postcss.config.js` — CSS-пайплайн.

# Technology Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS, shadcn/Radix UI.
- **Backend:** Python, FastAPI, Pydantic, SQLAlchemy.
- **Database:** реляционная БД через SQLAlchemy и Alembic.
- **Authentication:** Atoms Cloud authentication.
- **Storage:** Atoms Cloud object storage с хранением object keys.
- **Payments:** Stripe Checkout и серверная верификация платежей.
- **AI/Platform integrations:** Atoms Cloud Web SDK, AI Hub и custom API.
- **Localization:** собственный React i18n-провайдер для арабского и английского языков.
- **Content:** Markdown-блог с prerender и генерацией sitemap.
- **Quality tools:** ESLint, TypeScript, production build и Python syntax checks.
- **Deployment model:** cloud/serverless-compatible backend с frontend-сборкой Vite.

# Usage

## Backend

```bash
cd app/backend
pip install -r requirements.txt
alembic upgrade head
```

Настройте переменные окружения для базы данных, аутентификации, storage и Stripe согласно конфигурации проекта.

## Frontend

```bash
cd app/frontend
pnpm install
pnpm lint
pnpm build
```

Для разработки используйте:

```bash
pnpm dev
```

## Запуск всего приложения

```bash
cd app
bash start_app_v2.sh
```

После запуска доступны главная страница, onboarding, discovery, профили, сообщения, подписки, реклама, presence и блог. Для реального платежного сценария требуется подключённый Stripe-аккаунт; тестовые платежи выполняются в Stripe test mode.

## Проверки

```bash
cd app/backend
python -m compileall .

cd ../frontend
pnpm lint
pnpm build
```
